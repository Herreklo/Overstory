# Nature: inspiration from Totoro's summer countryside

Øystein, 30 October 2026: "Totoro's summer countryside really is a nice reference - not that we are doing THAT comic style, but loads to be inspired by". Kazuo Oga's backgrounds for *My Neighbor Totoro* (Studio Ghibli, 1988): how rock, stone, made things and ground grow together, and a summer light with joy in it. Inspiration for the rock's ground contact, the ground and growth, and the colour pass; never its drawing style, its characters or a measure. Studio Ghibli publishes these stills for free use "常識の範囲でご自由にお使いください" (within common sense); all 50 are in `~/code/overstory-sources/ghibli-totoro/` (logged in `docs/research/downloads.md`). These nine are kept for study only in `study/`, which git ignores.

## Summer colour, and nature as engaging as the town
