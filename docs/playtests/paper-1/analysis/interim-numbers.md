Where the GMs scored something, their score is used. Where this file codes something they did not, it says so ("my coding").

## Coding rules

- **Scores:** right 1, partly 0.5, wrong 0. A "no record" exit claim (the record neither holds nor denies it) is shown both ways: counted as wrong, and left out.
- **Predictions:** untested ones are left out of the denominator. Each run scored five or six, so one prediction moves a run by up to 16.7 points (20 where five were scored).
- **Pull:** six act pulls per run (`r1-act` is the opening). **Mean6** is over those six and is comparable across all 11. The concept exits did not ask for an overall pull. Where a player volunteered one, **meanExit** counts it as a seventh round, as calibration did. **Relative pull** = (concept − Saltlight) / (anchor − Saltlight), using calibration means.
- **Kind-flagged players** (the calibration check came out "kind"): X6, Y4, Y5. Their taste measures (pull, keep, buy) count half.
- **Model adjustment:** each kind's calibration prediction gap (Sonnet − Opus) is subtracted where lives on ran on Sonnet and added where it ran on Opus.
- **Misreading:** a prediction scored partly or wrong, or an exit claim scored partly, wrong or no record. The cause is as the GM coded it, "uncoded" where the GM gave none. Three exits were scored per person (mystery a/Y2, journalist b/X2, b/X5). I split those into misreadings from the GM's notes.
- **What or why (my coding):** "why" is a claim of cause, motive, link between events, or what an act meant. "What" is events, states, roles, kin, and who did something.
- **Causal claim (my coding, the prereg's confabulation check):** an exit claim that asserts a cause, motive, link or meaning. Denials ("nobody caused it") are left out.
