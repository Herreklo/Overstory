## Thinking aloud
Belonging went from 0 to 13% in four actions and I can't tell which action moved it. That's what bothers me most. A percentage with no visible rule is a number I can't play. I'd like the breakdown: so much for a conversation, so much for an inspection, so much for a new place? If I learn the rule I can plan; if it is a black box, it's a progress bar.

The clock does move: it was 8:10, now about noon, so my four actions cost nearly four hours. I'd assumed "no timers" meant the clock was cosmetic. The ferry at 13.00 and the Lantern Walk at dusk might be real appointments. The page said I can't miss anything, though, so I'll test it: sit and see whether time passing changes anything.

The cardigan "found on the steps" is a fetch quest in miniature, and it's the nearest thing to a goal I've seen. I'll go through June at the Kettle, who also likely knows about Tolley.
